System Architecture

The site is split into two completely separate services that work together:

🌐 Frontend — Cloudflare Pages

A single static HTML file containing the entire website. No React, no build process. Deployed by uploading a folder directly to Cloudflare. Served globally via Cloudflare's CDN.

Static HTML/CSS/JSCloudflare CDN
⚙️ Backend — PocketBase on Railway

A lightweight database + API server. Stores brand logos, contact form submissions and sell enquiries. Runs 24/7 on Railway. Hook scripts handle validation, spam filtering and email alerts.

PocketBase v0.23Railway
📐 Request Flow
# Visitor loads the site
Browser → Cloudflare Pages CDN → serves index.html (instant, cached globally)

# Page load: JavaScript fetches brand logos
index.html JS → Railway PocketBase API → logo records → applied to page

# Contact / Sell form submitted
Form JS → PocketBase API → hook validates + rate-limits
        → saves record to DB → sends email via Resend API → user sees ✓

Railway — Backend Server

PocketBase — Database & API

Admin Panel: rsda-pocketbase-production.up.railway.app/_/

PocketBase is the database. It stores all dynamic data and exposes a REST API that the website's JavaScript calls. The admin panel is a full UI for managing records.

Collections (Database Tables)

PocketBase Hook Files

Hooks are JavaScript files that run server-side on PocketBase for specific events. They live in the GitHub repo:

GitHub repo: rpatel-2019/rsda-pocketbase
Local path:  /Users/vapatel/Downloads/rsda-backend/pocketbase/pb/pb_hooks/

pb_hooks/
├── logos.pb.js       # Runs on logo create/update — sets defaults for zoom/x/y
└── enquiries.pb.js   # Runs on contact form submit:
                      #   1. Extracts real IP
                      #   2. Rate-limits (max 3 per IP per hour)
                      #   3. Sanitises input (strips HTML, trims, max lengths)
                      #   4. Spam filter (blocks casino/crypto/URL keywords)
                      #   5. Sends email notification via Resend API

To change hook logic: edit the file locally → git add . && git commit -m "description" && git push → Railway auto-redeploys.

⚠️ Two-Copy SPA Pattern — Important to Understand

Spam Filter — Blocked Keywords

The contact form automatically blocks messages containing: casino, viagra, crypto, bitcoin, nft, forex, seo service, backlink, make money, earn $, free money, click here, limited offer, any URL (http://). Also blocks: @example.com, @test.com, @mailinator.com emails.

To add or remove blocked keywords, edit enquiries.pb.js → the SPAM array → push to GitHub.

Changing the Rate Limit

In enquiries.pb.js find recent.length >= 3 and change 3 to your desired limit. The 3_600_000 is 1 hour in milliseconds.
